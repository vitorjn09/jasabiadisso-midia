Acesso ao GitHub

Para ver a agenda basta abrir esta página. Para adicionar, editar, apagar posts ou rodar o robô, cole aqui um token do GitHub. Ele fica guardado só neste navegador.

Como criar o token (uma vez só)
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Nome: "painel do robô". Validade: a que preferir.
  3. Repository access: Only select repositories → jasabiadisso-midia.
  4. Permissions → Repository: Contents: Read and write e Actions: Read and write.
  5. Generate token, copie e cole abaixo.
